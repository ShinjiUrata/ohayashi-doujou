譜面編集 設計メモ

  • ヘッダ:「中止」戻る + タイトル「譜面を編集」
  • CHART INFO セクション:曲名・地域名を編集(木札風カード内)
  • TIMELINE:譜面を時間軸で可視化。ノーツ種別ごとに色分け(ドン=赤丸、カッ=青小丸、両手ドン=金縁+大、ホールド=帯)
  • 再生ヘッド(金色縦線)で現在位置を表示
  • 編集ツール:再生 / 追加 / 削除 / 移動 の 4 モード
  • DIFFICULTY:易 / 中 / 難 の 3 段階を色分けボタンで選択
  • フッター 3 ボタン:
    • 試遊(セカンダリ木札)— アップロード前のプレビュー
    • 保存(下書き、ゴースト)— ローカル保存のみ
    • 公開する ¥1,000(プライマリ赤)— IAP フローへ
