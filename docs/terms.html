おはやし道場 利用規約

この利用規約(以下「本規約」といいます)は、株式会社ZembREM(以下「当社」といいます)が提供するリズム学習アプリケーション「おはやし道場」(以下「本サービス」といいます)の利用に関する条件および当社と利用者との間の権利義務関係を定めるものです。本サービスの利用にあたっては、本規約の全文をお読みいただき、内容を十分にご理解いただいた上で、本規約に同意していただく必要があります。

第 1 条(定義)

本規約において使用する用語の定義は、以下のとおりとします。

  1. 「本サービス」とは、当社が提供する iOS 用リズム学習アプリケーション「おはやし道場」およびその関連するすべての機能・サービスをいいます。
  2. 「利用者」とは、本サービスを利用するすべての者をいいます。
  3. 「譜面」とは、お囃子のリズムパターンを表現する、ノーツの時系列データその他の情報を含むデジタルコンテンツをいいます。
  4. 「公開譜面」とは、利用者が本サービスを通じて当社サーバーに公開手続きを行った譜面をいいます。
  5. 「制作者」とは、譜面を作成した利用者をいいます。
  6. 「プレイヤー」とは、公開譜面をダウンロードして再生する利用者をいいます。
  7. 「公開料金」とは、譜面 1 曲の公開に必要な料金をいいます(第 6 条参照)。

第 2 条(本規約の適用)

  1. 本規約は、利用者と当社との間の本サービスの利用に関わる一切の関係に適用されるものとします。
  2. 当社は本サービスに関し、本規約のほか、利用者に対し別途提示するガイドライン、ルール等の各種の定め(以下「個別規約等」といいます)をすることがあります。これらの個別規約等は、その名称にかかわらず、本規約の一部を構成するものとして適用されます。
  3. 本規約の規定と個別規約等の規定が異なる場合、個別規約等に特段の定めがない限り、個別規約等の規定が優先されるものとします。

第 3 条(アカウントの不設置)

本サービスは、利用者のアカウント登録および認証を必要としません。利用者は匿名で本サービスを利用します。App 内購入に関する Apple 社の利用規約の適用については、第 3 条の 2 に定めます。

第 3 条の 2(Apple の利用規約および EULA の適用)

  1. 本サービスは Apple 社の App Store を通じて配信されます。利用者は、本規約に加えて、Apple 社が定める以下の各規約に同意し、これらを遵守するものとします。
    • Apple メディアサービス利用規約
    • Licensed Application End User License Agreement(以下「Apple 標準 EULA」といいます)
  2. 本規約と Apple 標準 EULA との間に矛盾が生じた場合、Apple 標準 EULA の規定が優先されます。当社は Apple 標準 EULA の内容を修正するものではありません。
  3. Apple 社は本サービスの利用契約の当事者ではありませんが、Apple 標準 EULA に基づき、本サービスに対して受益者としての権利を有し、当該規約を第三受益者として利用者に対して行使することができます。

第 4 条(本サービスの内容)

  1. 本サービスは、利用者が iPhone のタッチ画面を通じてお囃子のリズムを学習することを目的としたリズムゲームアプリケーションです。
  2. 本サービスの主な機能は以下のとおりです。ただし、当社は本サービスの機能を予告なく追加、変更または削除することがあります。
    • 譜面のプレイ(再生 / 判定 / スコア表示)
    • 譜面の録音・編集(オフライン、無料)
    • 譜面のダウンロード(公開譜面 ID を指定した匿名取得、無料)
    • 譜面の公開(第 6 条に定める公開料金の支払いと引き換えの、当社サーバーへの譜面アップロード)
  3. 本サービスの以下の機能は、インターネット接続が必要です。
    • 譜面のダウンロード
    • 譜面の公開
  4. その他の機能(プレイ、録音、編集、ローカル譜面の管理)は、譜面のダウンロードまたはプレイ用に必要なデータが端末に保存されている限り、インターネット接続を必要としません。

第 5 条(譜面の作成・保存・自己利用)

  1. 利用者は、本サービスの録音・編集機能を用いて、譜面を無償で作成・編集・保存することができます。
  2. 作成した譜面は、利用者自身の端末内で自由にプレイし、内容を編集することができます。
  3. 端末内の譜面データは、本サービスが指定するアプリケーション専用ディレクトリに保存されます。利用者がアプリケーションをアンインストールした場合、これらのデータは削除されます。

第 6 条(譜面の公開 / App 内購入)

  1. 利用者は、自らが作成した譜面を、本サービスを通じて他の利用者がダウンロード可能な状態(以下「公開」といいます)に置くことができます。
  2. 譜面の公開には、譜面 1 曲あたり 1,200 円(税込)の公開料金の支払いが必要です。公開料金は、App Store の App 内購入(In-App Purchase)を通じて Apple に支払うものとし、決済手段・タイミング・返金等については Apple の定めに従います。
  3. 前項の App 内購入は、Consumable(消費型)商品として提供されます。利用者が公開ボタンを押下した時点で決済処理が開始され、決済成功時に当社サーバーへの譜面アップロード(役務の提供)が実行されます。役務の提供は決済処理の完了と同時に完結し、返金は原則として行われません(詳細は特定商取引法に基づく表記をご参照ください)。
  4. 本サービスの公開料金は、決済と同時に役務提供(譜面のサーバーアップロードおよび公開)が完結する即時消費モデルであり、資金決済に関する法律(平成 21 年法律第 59 号)第 2 条第 3 項に規定する前払式支払手段には該当しません。したがって、有効期限管理、供託義務、未使用残高の払戻し等の前払式支払手段規制の対象外です。
  5. 公開手続きにおいて、利用者は譜面 ID(半角小文字英字・数字・ハイフンからなる 3〜64 文字の文字列)を任意に指定します。当社サーバー上で未使用の ID のみ公開が許可されます(先願主義)。既に使用されている ID を指定した場合、公開手続きは中止され、決済も行われません。
  6. 公開手続きの完了により、当該譜面は当社サーバーに保存され、以後、譜面 ID を知る任意の者が匿名でダウンロード可能な状態となります。

第 7 条(公開譜面のライセンス)

  1. 制作者は、公開手続きを行うことにより、当社および公開譜面をダウンロードした利用者に対し、以下の権利を無償・非独占的・地域非限定・サブライセンス可能な形で許諾するものとします。
    • 譜面データを当社サーバーに保存・複製・配信する権利(当社に対する)
    • 譜面データをダウンロードして再生・複製・改変(自身のプレイ用途)する権利(プレイヤーに対する)
  2. 制作者は、前項に基づく利用について、当社および当社が許諾する第三者に対し、著作者人格権を行使しないものとします。
  3. 制作者は、公開する譜面について、自らが公開する適法な権利を有していること、および当該譜面が第三者の権利(著作権、著作隣接権、その他の権利)を侵害していないことを、当社に対し表明し保証します。
  4. 譜面の公開後、当該譜面のダウンロードおよびプレイヤーによる利用は、当社が譜面を削除するまでの間、継続するものとします。

第 9 条(公開譜面の削除・取り下げ)

  1. 当社は、公開譜面が以下のいずれかに該当すると判断した場合、事前の通知なく当該譜面を削除することができるものとします。
    • 第 8 条(禁止事項)に違反する内容が含まれると判断した場合
    • 第三者から権利侵害等の申し立てがあり、当社が削除相当と判断した場合

第 10 条(更新公開の不許可)

  1. 一度公開された譜面の内容を、同一の譜面 ID で更新(差し替え)することはできません。
  2. 譜面の修正版を公開したい場合は、別の譜面 ID による新規公開手続きが必要となり、あらためて公開料金の支払いが必要となります。
