お囃子道場 プライバシーポリシー

株式会社ZembREM(以下「当社」といいます)は、当社が提供するリズム学習アプリケーション「お囃子道場」(以下「本サービス」といいます)における利用者情報の取り扱いについて、以下のとおりプライバシーポリシー(以下「本ポリシー」といいます)を定めます。

1. 基本方針

当社は、利用者のプライバシーを最大限尊重するため、本サービスの設計において以下の原則を採用しています。

  • アカウントおよび個人情報の収集を行いません。 本サービスは利用者登録・ログイン等の認証手続きを一切必要としません。
  • 利用者の個人を識別する情報を保持しません。 氏名、メールアドレス、電話番号、住所、位置情報、生体情報、その他の個人識別情報を、本サービスは一切収集・保存しません。
  • オフラインでの動作を基本設計とします。 譜面のプレイ・録音・編集・保存は、すべて利用者の端末内で完結し、通信は発生しません。
  • 通信が必要な機能は最小限に限定します。 譜面の公開および譜面のダウンロードの 2 機能のみが、当社サーバーとの通信を必要とします。

2. 取得する情報

本サービスは、以下の情報を取得します。他の情報を取得することはありません。

2.1 譜面公開時に取得する情報

利用者が譜面公開機能を利用した場合、以下の情報を当社サーバーに送信・保存します。

項目内容保存場所
譜面 ID 利用者が公開時に指定した文字列 当社サーバー
譜面データ 譜面の名称、地域名、演奏時間、ノーツの時系列データ(利用者が編集画面で入力・作成した内容) 当社サーバー
決済トランザクション ID Apple から発行される決済識別情報 当社サーバー
公開日時 公開手続きが完了した日時 当社サーバー

これらの情報には、利用者を個人として識別する情報は一切含まれません。

2.2 譜面ダウンロード時のアクセス

利用者が譜面 ID を指定してダウンロード機能を利用した場合、以下のアクセスが発生します。

  • 当社サーバー(Google Cloud Storage)への HTTP GET リクエスト
  • リクエストには、譜面 ID のみが含まれます

当社は、譜面ダウンロード時のアクセスログを本サービスの安全な運用のために一時的に取得することがありますが、当該ログから利用者個人を特定することはできず、また、当該ログを他の目的で利用することはありません。

2.3 端末内に保存される情報

以下の情報は、利用者の端末内(本サービスのアプリケーション専用ディレクトリ)にのみ保存され、当社サーバーには送信されません。

  • 利用者が録音・作成した譜面データ(公開手続きを行わない限り、端末外に送信されません)
  • ダウンロードした譜面データ
  • 本サービスの動作に必要な設定情報

これらの情報は、利用者が本サービスをアンインストールした場合、削除されます。

3. 取得した情報の利用目的

当社は、前項で取得した情報を以下の目的でのみ利用します。

  1. 譜面の公開機能の提供(譜面データを他の利用者がダウンロード可能な状態にすること)
  2. 譜面のダウンロード機能の提供
  3. 決済の重複防止(同一のトランザクション ID が二重に使用されることを防止するため)
  4. 公開譜面 ID の重複防止(同一 ID を複数の譜面に割り当てないため)
  5. 本サービスの安全な運用および不正利用の防止
  6. 法令に基づく開示要請への対応

4. 第三者への提供

当社は、法令に基づく場合を除き、取得した情報を第三者に提供しません。

5. 業務委託先(データ処理を委託している事業者)

当社は、本サービスの運営にあたり、以下の外部事業者のサービスを利用しています。これらの事業者は、それぞれのプライバシーポリシーおよびデータ処理契約に基づき、データを適切に管理します。

事業者サービス用途
Apple Inc. App Store In-App Purchase 決済処理、決済結果の署名検証
Google LLC Google Cloud Platform(Cloud Run / Cloud Storage / Firestore) 譜面データの保存、公開機能の提供、決済トランザクション ID の管理

これらの事業者のプライバシーポリシーは、各社のウェブサイトをご参照ください。

  • Apple: https://www.apple.com/jp/legal/privacy/jp/
  • Google Cloud: https://cloud.google.com/terms/cloud-privacy-notice

6. データの保管場所および越境移転

譜面データおよび決済トランザクション情報は、Google Cloud Platform のアジア東北 1 リージョン(東京)内に保管します。ただし、Google Cloud のインフラ管理上、限定的な範囲で他のリージョンにデータが複製または処理される場合があります。詳細は Google Cloud のプライバシーポリシーをご参照ください。

7. データの保管期間

  • 公開譜面データ: 公開後、当社が本サービスの提供を継続する限り保管します。利用者からの取り下げ請求または当社の判断による削除が行われた場合、当社サーバーから削除されます。
  • 決済トランザクション ID: 決済の重複防止および税務・会計上の記録保存のため、決済日から 7 年間保管します。
  • アクセスログ: 安全な運用に必要な最短期間(原則 30 日以内)で削除します。

8. 情報の削除・訂正の請求

利用者は、当社が保管する公開譜面データについて、削除を請求することができます。請求は、下記お問い合わせ先までメールにてご連絡ください。

  • 譜面 ID を指定した削除請求: 制作者本人であることを確認できる合理的な情報の提供と引き換えに対応します
  • 譜面データの訂正: 更新公開機能は提供していないため、譜面の内容を訂正するためには、当該譜面を削除したうえで新しい譜面 ID で新規公開手続きを行っていただく必要があります(公開料金がかかります)

9. Cookie その他の追跡技術

本サービスは、Cookie、広告識別子(IDFA)、その他のトラッキング技術を一切使用しません。当社は、利用者の行動を分析するためのアクセス解析ツール、広告配信ネットワーク、SNS 連携等も一切利用していません。

10. 児童のプライバシー

本サービスは、子供が祭り会場等で遊ぶことを想定して設計されています。

  • 本サービスはアカウントを設けず、利用者の個人情報を一切取得しません。
  • 本サービスの App 内購入(譜面公開機能)は、保護者・大人による利用を想定しています。児童が App 内購入を行う場合は、必ず法定代理人(親権者等)の同意のもとに行ってください。
  • Apple の Family Sharing 機能および「承認と購入のリクエスト」機能を利用することで、児童の App 内購入を保護者が承認する運用が可能です。

11. セキュリティ

当社は、取得した情報の安全な管理のため、以下の技術的・組織的な安全管理措置を講じています。

  • 通信は HTTPS(TLS)により暗号化
  • サーバーは Google Cloud Platform の管理する日本国内リージョンで運用
  • 譜面データへのアクセス制御(公開譜面は譜面 ID を知る者のみがダウンロード可能)
  • 一覧取得 API を設けないことによる、譜面全体を大量取得するリスクの低減
  • 決済処理は Apple の App 内購入(In-App Purchase)に完全に委ね、当社は決済情報(クレジットカード番号等)を一切取り扱いません

12. 本ポリシーの変更

当社は、法令の改正、事業内容の変更その他必要があるときは、本ポリシーを変更することがあります。変更後の本ポリシーは、本サービス上での掲示その他当社が適当と判断する方法により周知した時点から効力を生じるものとします。
