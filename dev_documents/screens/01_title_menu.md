# タイトル / メニュー画面

## 概要

アプリ起動直後に表示される最初の画面。ユーザーがモードを選択する起点となる。
祭り会場でブースに置かれた iPhone を子供が触ったときに、迷わず「プレイ」に到達できることが重要。

## 主要 UI 要素

- タイトルロゴ(「お囃子道場」)
- 大きな CTA ボタン
  - **プレイ** — 保存済み譜面一覧へ
  - **録音** — 譜面を作る(指導者用)
- サブ導線
  - **譜面をIDで入手** — 譜面検索/DL 画面へ
- 設定 / About(Phase 6 以降で検討)

## ユーザーができること

- モードの選択(プレイ / 録音)
- 譜面ライブラリを開く
- 譜面 ID を入力して新しい譜面を入手する

## 必要な API / 通信

なし。完全ローカル画面。

## 周辺技術

- SwiftUI(トップレベル `NavigationStack` の起点)
- `@AppStorage` などで初回起動フラグを管理する余地あり(チュートリアル導入時)

## 遷移元 / 遷移先

- **遷移元**: アプリ起動時
- **遷移先**:
  - 「プレイ」→ 保存済み譜面一覧(02)
  - 「録音」→ 録音画面(06)
  - 「譜面をIDで入手」→ 譜面検索/DL(03)

## 対応 Phase

Phase 6(仕上げ) — 最小プロトタイプの段階ではプレイ画面(04)を直接立ち上げる。
本格的に整備するのはコア体験が完成した後。

## メモ

- 祭り会場運用時は「プレイ」ボタンが目立つ配色にする(子供が迷わないため)
- 「録音」「公開」は指導者/制作者向けの機能で、視覚的重み付けを下げる余地あり
