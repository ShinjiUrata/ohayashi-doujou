画面 03: 譜面検索 / DL

目的: ID を入力して譜面をサーバーからDLし、端末ローカルに保存

要素

ID 入力欄: 等幅フォント、小英数・ハイフンのみ
入力バリデーション: 文字種・長さ(3〜64)を UI 側で先に検証
ダウンロードボタン: 青系(プレイ経路の朱と区別)
オフライン説明カード: 祭り会場での安心感を明示

API

GET https://storage.googleapis.com/ohayashi-charts-{env}/{id}.json
200 → ローカル保存 / 404 → 見つかりません

コスト保護

同じ ID を再検索したときは既存ローカルファイルを検出して DL スキップ
