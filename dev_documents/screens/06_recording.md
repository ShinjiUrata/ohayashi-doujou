# 録音画面

## 概要

お囃子の指導者(または上手な子)がお手本を叩き、その打点を時系列で記録して譜面化する画面。
通常のプレイ画面とは異なり、**録音中だけ太鼓の面を左右に分割**表示することで、
タップ位置から `don_l` / `don_r` を推定する(案 2、CLAUDE.md §3.6)。

## 主要 UI 要素

- ヘッダ
  - 録音状態バッジ(●REC / 待機中)
  - 経過時間(mm:ss)
  - 終了ボタン
- 太鼓(左右分割表示)
  - 内側左半分 → `don_l`
  - 内側右半分 → `don_r`
- 外側のカッゾーン
  - 太鼓の左外側 → `ka_l`
  - 太鼓の右外側 → `ka_r`
- 録音開始 / 停止ボタン
- (任意)メトロノーム(補助、Phase 3 で判断)

## ユーザーができること

- 録音開始
- 太鼓を叩く(タップ位置に応じて `don_l` / `don_r` / `ka_l` / `ka_r` を記録)
- 効果音・触覚フィードバックを受け取る(実際に叩いている感覚)
- 録音停止 → 編集画面(07)へ

## タップ位置 → ノーツ種別のマッピング

| タップ位置 | 記録される type |
|---|---|
| 太鼓の左外側 | `ka_l` |
| 太鼓内側の**左半分** | `don_l` |
| 太鼓内側の**右半分** | `don_r` |
| 太鼓の右外側 | `ka_r` |

→ 録音時は左右のドンをタップ位置で **推定** して記録。指導者が左右を意識して叩けば自然に記録される想定。
完璧な精度は不要(意図が反映されれば十分、編集画面で微修正可能)。

## データ出力

録音停止時に譜面 JSON を生成:

```json
{
  "id": "",
  "name": "",
  "region": "",
  "created_at": "2026-07-02T10:30:00Z",
  "duration_ms": <録音時間>,
  "notes": [
    { "t": <ms>, "type": "don_l" | "don_r" | "ka_l" | "ka_r" }
  ]
}
```

- `id` / `name` / `region` は編集画面(07)で入力
- 一旦「ドラフト」として端末内に保存

## 必要な API / 通信

なし。完全ローカル。

## 周辺技術

- **SpriteKit** — 太鼓の描画、タップ位置判定、視覚エフェクト
- **AVAudioEngine** — 効果音再生(録音操作の打感)
- **UIImpactFeedbackGenerator** — 触覚フィードバック
- **CACurrentMediaTime** or `Date` — 録音開始からの経過時間計測
  - 高精度が必要なら `CACurrentMediaTime`(単調増加、システム時計変更の影響なし)
- **FileManager** — ドラフト譜面の一時保存

## 遷移元 / 遷移先

- **遷移元**: タイトル/メニュー(01)から「録音」
- **遷移先**:
  - 録音停止 → 譜面編集画面(07)
  - キャンセル → タイトル/メニュー(01)

## 対応 Phase

Phase 3(録音モード)

## メモ

- 録音中の太鼓分割表示は「録音中だけ」のUIモード切替(通常のプレイ画面は分割しない)
- メトロノーム機能の要否は Phase 3 実装時に判断(お囃子の性質上、拍が不明瞭な曲もあるため必須ではない)
- 打点の記録は「叩いた瞬間」の時刻のみ(長さ・強弱は取らない)
