# 譜面検索 / ダウンロード画面

## 概要

譜面 ID を入力してサーバーから譜面 JSON を取得し、端末ローカルに保存する画面。
本アプリでの譜面発見手段は **ID入力のみ**(一覧 API は存在しない)。制作者が地域内で告知した ID を打ち込む形。

## 主要 UI 要素

- ID 入力テキストフィールド
  - プレースホルダ例: `shimoda-2026-irihayashi`
  - 入力制約: 小英字・数字・ハイフンのみ、3〜64文字
- ダウンロードボタン
- ローディングインジケータ
- エラーメッセージ表示エリア
  - 404: 「この譜面IDは見つかりません」
  - ネットワークエラー: 「通信に失敗しました。電波状況をご確認ください」
- (将来)QR スキャンボタン

## ユーザーができること

- ID を手入力して譜面を DL
- DL 成功時、譜面が保存済み一覧(02)に追加される
- 既に保存済みの ID なら DL をスキップして「保存済みです」表示

## 必要な API / 通信

### 譜面取得
```
GET https://storage.googleapis.com/ohayashi-charts-{env}/{id}.json
```
- `{env}` = `dev` or `prod`(xcconfig で切替)
- 独自ドメイン不採用、GCS の直接 URL を利用
- 認証なし(匿名 GET)
- レスポンス
  - `200 OK` — 譜面 JSON をそのまま受け取り、`{id}.json` としてローカル保存
  - `404 Not Found` — 未公開 or 存在しない
  - 5xx — 一時エラー(リトライ導線)
- **注意**: 譜面一覧 API は存在しない。バケットの ListObjects 権限も付与されていない

## 周辺技術

- `URLSession` (async/await)
- `JSONDecoder` で受信データを検証(`id` / `notes` / `duration_ms` が存在するか)
- `FileManager` でローカル保存
- ローカル重複チェック(既存 `{id}.json` があれば DL スキップ)
  - コスト保護対策(GCS への無駄な egress を抑止)

## セキュリティ / コスト対策

- **クライアント側キャッシュ徹底**(`dev_documents/implementation_notes/cost_protection.md` §2C)
  - 同じ ID を何度検索してもローカルヒットで完結させる
- 誤入力での連続 DL を防ぐため、入力バリデーション(文字種・長さ)を UI 側で先に済ませる

## 遷移元 / 遷移先

- **遷移元**:
  - タイトル/メニュー(01)から「譜面をIDで入手」
  - 保存済み譜面一覧(02)のヘッダから「IDで入手」
- **遷移先**:
  - DL 成功 → 保存済み譜面一覧(02)に戻る(新しい譜面がハイライト表示されると尚良い)
  - キャンセル → 遷移元へ戻る
