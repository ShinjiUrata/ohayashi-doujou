# 保存済み譜面一覧画面

## 概要

端末ローカル(アプリ専用ディレクトリ)に保存された譜面をリスト表示する。
プレイの起点であり、譜面の管理(削除・リネーム)もここから行う。

## 主要 UI 要素

- 譜面リスト(セル)
  - 譜面名(`name`)
  - 地域名(`region`)
  - 収録時間(`duration_ms` を分:秒表示)
  - 作成日時
- 空の状態(譜面ゼロ件時)
  - 「まだ譜面がありません」+ 「IDで入手」「録音する」導線
- 追加ボタン(ヘッダ)
  - 「IDで入手」→ 譜面検索/DL(03)

## ユーザーができること

- 譜面を選んでプレイ開始
- 譜面の削除(スワイプ)
- 譜面のリネーム(Phase 6)
- 新規譜面の入手(ID検索)への導線

## 必要な API / 通信

なし。ローカルファイルシステムのみ参照。

## 周辺技術

- SwiftUI `List` / `NavigationLink`
- `FileManager` でアプリ専用ディレクトリ配下を走査
  - 例: `Application Support/charts/` サブディレクトリ配下の `*.json`
  - `Documents/` 直下ではなく別サブディレクトリで管理(`UIFileSharingEnabled = false` の運用と整合)
- `JSONDecoder` で譜面メタデータ(`id`, `name`, `region`, `created_at`, `duration_ms`)を読み込む
  - 一覧表示時は `notes` 配列を読み飛ばす軽量パースが望ましい(将来的な最適化余地)

## ローカル保存の設計

- 保存先: アプリ専用サブディレクトリ(`Documents/` 直下は避ける)
- ファイル名: `{id}.json`
- 保存タイミング:
  - DL 成功時(検索/DL 画面から)
  - 録音・編集後の保存操作
  - 公開成功後は自動的に保存されている状態

## 遷移元 / 遷移先

- **遷移元**:
  - タイトル/メニュー(01)から「プレイ」タップ
  - 譜面検索/DL(03)完了後
  - 譜面編集(07)保存後
  - リザルト(05)から「戻る」
- **遷移先**:
  - セル選択 → プレイ画面(04)
  - 「IDで入手」→ 譜面検索/DL(03)

## 対応 Phase

Phase 3(録音モード完成時に譜面一覧が必要になる)

## メモ

- MVP では並び順は「作成日 降順」で固定
- 検索・タグ・お気に入りなどは不要(譜面数が少ない想定)
