# リザルト画面

## 概要

プレイ終了後にスコア・戦績を表示する画面。子供にとっての「達成感」を演出する。

## 主要 UI 要素

- 総合スコア(大きく表示、金色ハイライト)
- 内訳
  - 良の数
  - 可の数
  - 不可の数
  - 最大コンボ
- 総合評価(星 or ランク、Phase 2 で仕様決定)
- ボタン
  - **もう一度プレイ** → プレイ画面(04)へ再突入
  - **一覧に戻る** → 保存済み譜面一覧(02)へ

## ユーザーができること

- スコア確認
- 同じ譜面をもう一度プレイ
- 譜面一覧に戻る

## 必要な API / 通信

なし。スコア共有機能は仕様上存在しない(アカウント/認証なし方針)。

## 周辺技術

- SwiftUI(静的レイアウト + シンプルなアニメーション)
- 効果音(達成ジングル、Phase 6 で追加検討)

## 遷移元 / 遷移先

- **遷移元**: プレイ画面(04)の完了時
- **遷移先**:
  - 「もう一度」→ プレイ画面(04)
  - 「一覧に戻る」→ 保存済み譜面一覧(02)

## 対応 Phase

Phase 2(譜面再生の完成時)

## メモ

- スコアはローカルにも保存しない(仕様上不要、UX を最大限シンプルに)
- 将来的にベストスコアのローカル保持は追加余地あり
