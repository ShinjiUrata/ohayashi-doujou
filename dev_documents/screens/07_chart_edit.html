画面 07: 譜面編集

目的: 録音後のメタデータ入力・ノーツ確認・試遊 / 保存 / 公開への導線
ここまで全部無料
試遊も保存もローカルで完結。課金は「公開」ボタン以降のフローでのみ発生する。

要素

メタデータフォーム: 譜面名 / 地域名
サマリ: 時間 / ノーツ数 / ドラフト状態
ノーツリスト: 時刻順 + type バッジ、× で個別削除
試遊: プレイ画面へドラフトのまま渡す
保存: 端末ローカルに書き出し
公開: 課金フローへの入口(青色で強調)

データ

入力: 録音済みドラフト JSON
保存先: Application Support/charts/{id}.json

遷移

試遊 → 04 プレイ(戻り先はこの画面)
保存 → 02 譜面一覧
公開 → 08 公開(IAP)
破棄 → 01 タイトル
※ ノーツの位置微調整 UI は MVP では未実装(削除のみ)
※ 完璧な精度は不要、意図が反映されれば十分の設計方針
