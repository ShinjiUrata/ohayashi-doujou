# プレイ画面

## 概要

譜面を再生しながらノーツをタップして遊ぶ、本アプリのコア体験画面。
太鼓の達人風のリズムゲーム UI(4レーン + 判定ライン + 太鼓)。
`mockups/play.html` にビジュアル方向性が確定済み。

## 主要 UI 要素

- ヘッダ(曲名 / スコア / コンボ / 終了ボタン)
- 4 レーン(視覚教育用)
  - 1: 左カッ / 2: 左ドン / 3: 右ドン / 4: 右カッ
- 判定ライン(Hit Line、金色の横線)
- 判定リング(4個、ラインの上)
- ノーツ(上から下へ落下)
  - ドン: 赤い大きめの円 + 「左」「右」表示
  - カッ: 青い小さめの円 + 「左」「右」表示
  - **大ドン(`don_both`)**: 赤い最大サイズの円 + 「両」文字 + 二重グロー、レーン 2/3 中央にまたがる
  - **ホールドノート(`duration > 0`)**: 頭 + 尾(帯)の形、尾は継続時間に比例する長さ
- 太鼓(画面下部、上部 6〜7 割を表示)
- タップ判定ゾーン(3 区分、視覚的なガイドは薄めに)
  - 太鼓の左外側 → `ka_l`
  - 太鼓の内側(中央) → `don`(don_l / don_r 共通)
  - 太鼓の右外側 → `ka_r`
- 視覚エフェクト
  - タップ位置に波紋
  - 太鼓が一瞬光る
  - 判定文字「良 / 可 / 不可」

## ユーザーができること

- ノーツをタイミングよくタップして遊ぶ
- 打感の効果音とハプティクスを受け取る
- 途中で終了(ヘッダの終了ボタン)

## 判定仕様

- タップ位置で 3 ゾーン判別
- タイミング判定窓(暫定)
  - 良: ±200ms
  - 可: ±400ms
  - それ以上: 不可
- **両手同時打(`don_both`)**: 中央ゾーンの左半分 + 右半分に 50ms 以内の 2 タッチが検出されれば成立、その上で通常のタイミング判定を適用
- **ホールドノート(`duration > 0`)**: 頭(開始)+ 尾(終了)の 2 段判定
  - 頭: 通常タイミング判定(良/可/不可)
  - 尾: `t + duration` の時刻でリリース、±150ms 以内で成立
  - 途中で離した場合は「不完全ホールド」で加点少なめ、コンボは維持
- 数値は試遊して調整(§8 未決事項)

## 必要な API / 通信

なし。譜面はローカル保存済みの JSON を読み込むだけ。プレイ中は完全オフライン。

## 周辺技術

- **SpriteKit** (`SKScene`) — ノーツ落下・当たり判定・エフェクト
- **SwiftUI** — 画面ラッパー(`SpriteView`)、ヘッダ、ボタン
- **AVAudioEngine** — 効果音再生(ドン / カッの WAV、アプリバンドル同梱)
- **UIImpactFeedbackGenerator** — 触覚フィードバック(軽い振動)
- **CADisplayLink**(SpriteKit 内部で使用)— 60/120 Hz のフレーム同期

## データ入力

- 譜面 JSON(ローカル `{id}.json`)
- `notes` 配列を時刻順に走査し、`t` に応じて画面上部からノーツを生成
- 落下速度: モックでは 3 秒。実機で調整(§8 未決事項)

## スコアリング

- 良: 高得点 / コンボ加算
- 可: 中得点 / コンボ加算
- 不可: 加算なし / コンボリセット
- 具体値は Phase 2 で決定

## 遷移元 / 遷移先

- **遷移元**:
  - 保存済み譜面一覧(02)からセル選択
  - 譜面編集(07)から「試遊」
  - リザルト(05)から「もう一度」
- **遷移先**:
  - 譜面終了 → リザルト(05)
  - 途中終了 → 保存済み譜面一覧(02) or 遷移元(編集/試遊時)

## 対応 Phase

- Phase 1: 静的レイアウト、単一ノーツの落下、タップ判定、効果音
- Phase 2: 譜面 JSON 読み込み、複数ノーツ、スコア/コンボ
- Phase 6: 視覚エフェクト、触覚フィードバックの仕上げ

## メモ

- 楽曲(BGM)はなし。ノーツと打感の効果音のみ
- キャリブレーション機能なし(iOS タッチの低遅延 + 楽曲なし構成のため)
- レイテンシ要因は入力遅延 + 表示遅延のみ
