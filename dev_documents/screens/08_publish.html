画面 08: 公開(IAP)

目的: 譜面をサーバーにアップロードして他端末で DL 可能にする。本アプリで唯一の課金ポイント
資金決済法の設計配慮
Consumable かつ「購入と役務提供が同時」設計。前払式支払手段に該当しないため、有効期限管理・供託義務は不要。

要素

譜面サマリ: 公開対象の情報を最終確認
公開ID入力: 制作者が自由に決める(早い者勝ち)
ID 事前確認: 課金前に /check-id で重複チェック
価格カード: ¥1,000 を目立たせる
公開ボタン: 決済ダイアログ起動 → 成功時 /publish

API / 課金

POST /check-id(事前確認、無料)
POST /publish(JWS + 譜面 JSON)
IAP: rhythm.chart.publish.single(Consumable)

技術

StoreKit 2(product.purchase())
Cloud Run 側で JWS 検証・Firestore 台帳記録

遷移

成功 → 完了エリア(発行ID表示)→ 02 譜面一覧
キャンセル → 07 編集に戻る

Phase

Phase 4(バックエンド接続)
Phase 5(IAP 統合)
※ 更新公開機能は持たない(取り下げ→再公開の課金回避を防ぐため)
※ 修正したい場合は別 ID で新規公開
